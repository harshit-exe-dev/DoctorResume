# DoctorResume — the resume clinic 🩺

**Your resume called in sick.** DoctorResume X-rays your resume for everything applicant
tracking systems (ATS) hate, gives it a health score out of 100, and writes the prescription —
including a brand-new, ATS-friendly resume generated from your own content.

## What it does

- **8-point inspection** — contact info, file health (including an X-ray for embedded
  graphics in PDFs), length, section anatomy, keyword bloodwork (calibrated to your target
  role), impact language (action verbs + quantified results), professional polish, ATS structure
- **Medical-chart diagnosis report** — health-score gauge, vitals, chief complaints,
  full-body scan with severity ratings, and a prioritized ℞ prescription of fixes
- **Treatment plan** — one click rebuilds your resume as a clean, single-column,
  ATS-safe document you can edit inline and print to PDF
- **100% private** — PDF/DOCX parsing and all analysis run locally in your browser.
  Your resume is never uploaded anywhere.

## Roles covered

Full-Stack, Frontend, Backend, Data Analyst, UI/UX, and General — each with its own
keyword bank for the bloodwork check.

## Run it locally

```bash
npm install
npm run dev
```

## Tech

React 19 + Vite + Tailwind CSS v4 · pdfjs-dist (PDF parsing + image X-ray) · mammoth (DOCX)
